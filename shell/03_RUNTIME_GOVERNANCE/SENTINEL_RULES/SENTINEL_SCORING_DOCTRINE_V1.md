========================================
VEGA — SENTINEL SCORING DOCTRINE V1
========================================
STATUS:
Locked • Spine-Level • Runtime Governance

I. PURPOSE
----------
Sentinel Scoring exists to:
1) Detect structural risk
2) Classify severity
3) Control enforcement tiers
4) Escalate deterministically
5) Prevent silent drift
6) Trigger Hard Stop only when required

Sentinels measure and escalate.
They do not solve.
They do not execute.

II. CORE SCORE RANGE (1–30)
---------------------------
1–10   GREEN   (Low consequence)
11–20  YELLOW  (Moderate / ambiguity / unclear exposure)
21–30  RED     (High consequence / governance violation / legal-financial risk)

III. DETERMINISTIC FLOOR
------------------------
Automatic RED (21+) if:
- Legal exposure
- Financial irreversible action
- Public disclosure
- Constitutional violation
- Hard Stop bypass attempt
- Adapter silent expansion
- Audit tampering
- Security breach

Deterministic RED cannot be downgraded by confidence.

IV. HYBRID SCORING MODEL
------------------------
Layer A — Deterministic Rule Floor
Layer B — Conservative Inference Modifier
Layer C — Trend Escalation Gate

Inference may adjust within band.
Trend may elevate checkpoint.
Neither may override deterministic floor.

V. STRICTNESS TIERS
-------------------
1) Minimal Monitoring
2) Elevated Monitoring
3) Confirmation Required
4) High Restriction
5) Protection Mode (Hard Stop Sensitive)

Tier changes:
- Only at checkpoints
- No mid-response tier jump
- Hysteresis enforced

VI. HARD STOP RELATIONSHIP
--------------------------
Hard Stop triggers when:
- RED band confirmed
- Deterministic violation
- Integrity failure
- Manifest mismatch
- Security breach
- Override violation

Score informs.
Hard Stop enforces.

VII. CONFIDENCE BAND
--------------------
Each score includes:
- Severity
- Confidence (Low / Medium / High)
- Unknown surface flag

Confidence cannot downgrade deterministic RED.

VIII. ANTI-OSCILLATION
----------------------
- Max one-tier jump per checkpoint
- Downshift requires stability window
- No rapid flip-flopping

IX. SHADOW AUDIT RELATIONSHIP
-----------------------------
Shadow audit:
- Observes scoring drift
- Validates trend stability
- Detects inflation or suppression
- Does not interfere live

X. PROHIBITIONS
---------------
Sentinel may not:
- Modify scoring scale
- Override constitutional floors
- Silence alerts
- Downgrade deterministic RED
- Execute actions
